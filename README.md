# Experiment 1 Git Operations

This repository demonstrates Git and GitHub operations in Visual Studio Code: initialization, status checks, staging, commits, remote push and pull, branches, comparison, merge, and a pull request.

## Contents

- `experiment1/status-demo.txt` shows a tracked file updated on a feature branch.
- `experiment1/new-file.txt` shows a file added on that branch.

The step-by-step procedure and command evidence are in the accompanying Experiment 1 report.
